# 禾字：认几个字，多一分自在

## 产品出发点
面向有生活经验、识字基础较弱的成年及老年用户。帮助他们认懂生活中的字，减少依赖，获得新的学习与交流活动。避免“文盲”“补课”等标签，也不使用儿童奖励语气。识字不能单独解决精神生活匮乏，需要生活应用和亲友陪伴。

首版假设：用户会刷手机，但不一定能读菜单；子女可帮助首次打开。优先移动端 H5 验证，后续微信小程序降低入口成本，不先开发复杂原生 App。

## 核心设计
- 取消文字首页，首次打开直接显示第一个字；上下滑动切换，自动尝试朗读，喇叭可重复播放。课程仍按场景整理，但不要求先选课。
- 先图景与声音，再字形，再词语和生活短句；拼音是辅助，不能成为入门门槛。
- 所有关键操作具备图标、文字和可重复语音说明。最终版本首次进入自动引导，需遵守设备音频播放限制。
- 先听后选，再在真实短句、指示牌中辨认。最终评估去掉图、拼音和例词，减少靠提示猜答案。
- 错误用“没关系，再看一次”，不倒扣、不排名、不清零；允许暂停。
- 大字、高对比、56px 以上按钮、少层级，无广告和刷屏内容。
- 尊重成年学习者：使用菜市场、田野、公交等成人场景；真实照片优先。Demo 使用 emoji，正式课程需真人测试替换。

## 学习闭环与课程
熟悉场景 → 单字听读 → 听音辨字 → 词句辨认 → 次日/第3/7/14天复习 → 真实生活任务。

| 阶段 | 建议内容 | 目标 |
| --- | --- | --- |
| 体验 | 100 字、10 主题、40 小课（本 Demo） | 验证能独立完成，不声称掌握 |
| 入门 | 30 课、90 字（待教研） | 认识厨房、出行、家庭常见字 |
| 实用 | 数字、价格、时间、路牌、手机基础 | 能处理生活中的短信息 |
| 扩展 | 家乡故事、兴趣阅读、给家人留言 | 建立持续使用的理由 |

不能把“打卡”当成“学会”。正式课程用跨天无提示辨认衡量保持率，教研处理近形字、同音字、多音字和普通话/方言差异。医疗场景只教识读，不自动推断药量和用药方式。

## 免费与 99 元学习约定
这是待验证的坚持机制，不预设有效。建议完整课程永久免费、无付费解锁、无广告。先试学再自愿加入；不默认勾选、不暗示付钱才能认真学习。

用户原始想法是“学习完课程返还”。建议版本：99 元自愿约定金，完成明确课程及跨天巩固后原路全额返还；不规定连续打卡，不设过期没收；因病、照护、不会操作等随时退出申请全额退款。子女代付需明确退款回原付款人。退出退款会弱化金钱约束，但能避免把坚持困难转化为损失，可和家人鼓励/提醒对照测试。

Demo 明确不收钱、不退款，仅模拟。Demo 条件为 100 字每字连续两次正确回答，不要求跨天，因此不能作为生产结业判定。生产规则建议每字至少两次跨天无提示正确识别，允许补练、人工复核和申诉，规则在付款前用语音解释并记录确认。

正式收款前需确定主体、支付渠道、资金管理、退款时限与协议，并向相应专业人士确认适用要求。本设计不构成已验证的收款合规结论。不能把未退约定金算作营收：需要覆盖全部余额的退款能力，账本以分计价，支付/退款回调验签、幂等、对账、失败重试及人工退款通道。

长期运营成本来自教研、语音录制、服务器和陪伴。优先创始人预算、公益支持、社区合作及透明自愿捐助；捐助与约定金分开，不能依赖学习者失败获利。

## 留存与陪伴
- 默认累计学习天数，不突出断签。
- 允许学过的字重复听，完成后有可读的短句或生活小任务。
- 后续由本人自愿开启亲友鼓励、选择时间提醒；不默认分享学习成绩，不给子女监控权限。
- 先通过真人录音和方言提示帮助进入，再逐渐关联普通话读音。不强制语音识别评判方言发音。

## 验证计划
先找 5–10 位用户，包含不同识字水平和手机能力。子女只负责打开页面，观察而不代答。
1. 无指导能否在 30 秒内开始；错误时能否继续。
2. 能否听到中文声音；按钮位置、字号是否合适。
3. 当天学过的字，第二天无图提示认对多少；和“答题率”分别记录。
4. 7 天内主动回来多少次，为什么回来或不来。
5. 免费、亲友陪伴、约定金三种机制需要更大样本才能比较；先不向试验老人收钱。

## 技术路径
Demo：无依赖 HTML/CSS/JavaScript，预生成火山 TTS MP3、localStorage、本地中国时区日期，数据不上传。按字保存正确序列和复习时间。一个回答会改变复习间隔，错题立即到期。

正式版：H5/小程序 + 后端 API + 关系数据库；用户、授权亲友、版本化课程、练习事件、复习计划、支付/退款独立模型。服务端判断结业，客户端不能直接写通过状态。教研提供可授权使用的图片、人工中文音频；匿名试学后可自愿绑定账户同步。学习事件尽量少采集，删除/导出与授权撤销可用。

## Demo 边界
无账户/云同步、真实支付、推送提醒、真实方言、手写/语音评测、自动生字识别；启动先补齐固定音频，学习时只播放本地文件。首次正确答题只表示练过，不能声称已掌握。清除浏览器数据会清除进度。

## 2026-10-10：直接刷字卡
入口不要求识字：一屏一个字，场景图标 + 大字 + 生活词句，上滑下一个，下滑回看，喇叭重复听。再次打开恢复上次浏览位置。语音使用说明收在辅助入口，主流程无需读说明。

可选认字练习通过 ? 进入，题目先读出，选择后以语音和符号反馈；随时回到字卡。浏览、完整听过、练习答对分别记录，不以刷卡次数判断学会。原有学习约定留在辅助功能中，不出现在学习入口。

浏览器自动播放限制采用醒目的喇叭按钮兜底，复用同一音频元素；需真实手机验证。不强制测试、不自动无限滚动、不把停留时长当掌握。

## 2026-10-12：完整常用字库
3500 字一级字表作为基础字库，原有 100 字精编生活卡排在最前。扩展字提供字形、主读音和可选辨认练习；没有核对过的生活例词和例句不自动编造。多音字主读音不能替代词语教学。

前端最多挂载 5 张卡，保存旧进度，避免大量 DOM。原有模拟约定仍只考核 100 字生活课程。音频总目录 14101 段，新增 13600 段需后续合成；详见 character-data.md。
