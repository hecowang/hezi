# 常用字库：3500 字

## 覆盖范围与来源

本版本完整覆盖《通用规范汉字表》（2013）一级字表 3500 个常用字，不含二级/三级中的低频字。一级字表用于基础教育和文化普及，不等同于每个字都适合老人作为第一课学习。

- 官方说明：https://www.moe.gov.cn/jyb_xwfb/xw_fbh/moe_2069/s7135/s7562/s7569/201308/t20130827_156353.html
- 字表转录：https://github.com/shengdoushi/common-standard-chinese-characters-table/blob/master/level-1.txt （blob `531714c8e74a092517ba7cbe7a72db3896bb591c`）
- 拼音、笔画、部首、分级字段：https://github.com/mapull/chinese-dictionary/blob/main/character/common/char_common_base.json （blob `94409434006f4c511a9bc71207f8fe9258b1f591`，MIT，保留 `data/mapull-LICENSE.txt`）
- 主读音：Unicode 17.0.0 Unihan 的 `kMandarin`，https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip （Unicode License v3，保留 `data/Unicode-LICENSE.txt`）

字表转录与基础字典的 3500 字集合完全一致；全部字符都有 Unihan 主读音。完整单字列表保存为 `data/level-1.txt`。本版本使用事实型字形与读音数据，没有复制字典释义或古文例句。

## 数据结构

`data/characters.js` 中每条记录为：

`[汉字, 主读音, 其他候选读音, 笔画数, 部首, 一级字表序号, 来源分组, 主读音数字拼音]`

来源分组是上游数据的粗粒度分类，不是精确词频排名。一级表原始序号以笔画编排，也不能当作词频排名。多音字候选包含字典读音，个别读音只用于特定词语或旧用法，不能把它们解释为随意互换。

原有 100 字生活课程排在最前，索引、词句和已有音频保持不变。其余字按来源分组、字表序号排列，提供基础字形和主读音卡片；暂不宣称已经为全部 3500 字编好生活例词、配图或多音字完整课程。扩展词句应经过教研核对后逐批加入。

## 播放与学习状态

页面只挂载当前附近最多 5 张卡，避免 3500 张卡一起占用手机内存。进度按汉字保存，旧的前 100 字位置和答题记录保留。

扩展字卡的火山合成任务携带 `pronunciation_dict.tone`，指定当前目标字的主读音；音频缓存键包含发音规则，改读音时才重生成。需要支持发音词典的 `seed-tts-2.0` / `seed-icl-2.0` 资源。字典主读音只是单字入口，不代表词语中所有实际读音；正式教学需要生活例词说明。

原有 99 元模拟学习约定仍对应 100 字生活课程，扩充字库不会自动把返还门槛提高到 3500 字。

## 音频规模

- 原有 100 字：501 段音频。
- 扩展 3400 字：每字 4 段（单字朗读、听音题目、正确反馈、错误反馈），单字简读与讲解共用。
- 完整目录：14101 段；已有 501 段缓存时，新生成 13600 段。

本次只扩充字库与生成目录，未批量调用火山生成 13600 段音频。`npm run audio:check` 可以不计费检查缺失量；`npm start` 有密钥时仍按原先约定补齐所有缺失音频，首次扩充合成耗时较长并消耗账户额度。没有密钥时保留已有音频离线启动，未生成的字不能播放。

为避免首次阻塞过久，可在 `.env` 设置 `VOLC_TTS_MAX_NEW_CLIPS=100`，或使用 `npm run audio:generate -- --limit 100` 每批制作 100 段；默认为 `0`，仍全量补齐。分批后生成清单仅记录实际存在的音频，下一次运行继续制作剩余片段。
