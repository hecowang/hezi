# 禾字 Hezi

为识字基础较弱的成年与老年人做的生活识字 Demo：**认几个字，多一分自在。**

## 体验

```bash
npm start
```

打开 http://localhost:8080 。无需安装依赖；需要 Python 3。也可使用任何静态服务器托管本目录。手机在同一 Wi-Fi 下访问电脑的局域网 IP:8080（需允许对应网络访问）。不要直接以 file:// 打开，ES Modules 需 HTTP。

- 4 个生活场景、12 个常用字；大字卡片、中文慢速朗读、听音选字。
- 按字记录练习结果，1/3/7/14 天复习间隔；错题进入即时复习。
- 当前浏览器保存进度，按中国时区累计学习日期，漏学不清零。
- 自愿 99 元学习约定和返还/退出流程全部为模拟，**不发生资金交易**。

见 [完整产品设计](docs/product-design.md)：目标人群、课程、交互、坚持机制、资金规则建议、用户验证与正式版路线。

## 检查

```bash
npm test
node --check app.js
```

单元测试覆盖复习时间、错题重置、模拟返还条件及日期时区。界面采用响应式布局，主要操作支持键盘与触屏。

## 文件

`index.html` 页面入口；`style.css` 样式；`app.js` 页面与交互；`course.js` 课程与学习状态；`tests/` 学习规则测试。

## 注意

中文朗读依赖设备的浏览器语音引擎；无中文语音时会提示，请家人协助。Demo 不是正式教学或收款产品，没有云同步，清除浏览器数据会丢失进度。正式版应使用真人音频、真人验证课程和服务端结业判定。现有 Apache-2.0 LICENSE 保留。
